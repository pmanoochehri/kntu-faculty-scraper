## ✨ Features

- 🔄 **Automated Web Scraping** - Extracts faculty data from KNTU website
- 🚀 **EdgeDriver Integration** - Uses Microsoft Edge for reliable automation
- 📊 **Pandas Power** - Clean data manipulation and analysis
- 📁 **Multiple Export Formats** - Excel, CSV, and JSON support
- 🔍 **Auto-Filter & Formatting** - Excel file with filters and auto-width columns
- 📋 **Data Sorting** - Automatically sorted by academic field (A-Z)
- 💾 **Backup System** - Automatic timestamped backups
- 🧹 **Duplicate Removal** - Clean data with no duplicates
- 🎯 **User-Friendly** - Clear progress indicators and summary statistics
